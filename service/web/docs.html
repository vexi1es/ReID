GET /api/health Состояние сервиса, размер галереи, GPU/CPU, порог ▼

Возвращает статус доступности, количество ТС в галерее, активный вычислительный провайдер (CPU / CUDA) и калиброванный порог.

// Нажмите «Выполнить запрос», чтобы получить ответ от сервера
GET /api/demo/queries Примеры запросов из test_query.csv (кадр + готовая рамка) ▼

Возвращает массив 20 тестовых кадров с готовыми координатами bbox (`x, y, w, h`) и ссылкой на полный снимок.

ПараметрТипПо умолчаниюОписание
limitinteger (query)24Максимальное число примеров
seedinteger (query)0Сид случайной выборки
// Ответ появится здесь
POST /api/search Найти автомобиль в галерее (ранжирование и вердикт) ▼

Принимает кадр и координаты рамки в пикселях исходного разрешения. Возвращает вердикт (`refused: true/false`), лучшего кандидата и top-N ранжированных совпадений.

Поле формыТипОбязательноеОписание
filebinary (JPEG/PNG)ДаСнимок с камеры (до 25 МБ)
x, y, w, hnumberНетКоординаты автомобиля (без них — весь кадр)
thresholdnumberНет (0.30)Порог уверенности совпадения (0.0–0.90)
top_kintegerНет (10)Количество кандидатов в ответе (1–30)
exclude_same_camerabooleanНет (true)Исключать кадры с той же камеры
// Ответ поиска появится здесь
GET /api/gallery Список объектов галереи с пагинацией ▼

Возвращает массив объектов галереи (ID, метка, номер камеры, источник).

ПараметрТипПо умолчаниюОписание
offsetinteger (query)0Смещение пагинации
limitinteger (query)50Количество возвращаемых объектов (до 500)
// Ответ появится здесь
GET /api/gallery/{id}/crop Превью автомобиля из базы (JPEG, длинная сторона 256 px) ▼

Отдаёт готовое изображение вырезанного автомобиля по его ID в галерее.

POST /api/demo/load Фоновая загрузка тестовой базы (750 автомобилей) ▼

Запускает индексацию тестовой выборки `test_gallery.csv`. Прогресс отслеживается через `GET /api/demo/status` (`done`, `total`, `running`).

DELETE /api/gallery Очистить всю базу галереи ▼

Удаляет все записи и очищает поисковый индекс. В режиме «только чтение» возвращает HTTP 403.
