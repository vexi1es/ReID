как это работает

Цифровой отпечаток машины вместо номера

  1. Рамкамашина вырезается по рамке (детектор находит её сам)
  2. Две нейросетиDINOv2 ViT-B и DINOv3 ConvNeXt-S, дообученные на машинах, дают отпечаток из 2304 чисел
  3. Камера по фонумашина закрашивается, по фону кадра определяется камера; кадры той же камеры не мешают поиску
  4. Поискближайшие отпечатки в базе FAISS; уверенность — косинусная близость
  5. Решениекандидат с уверенностью или честный отказ ниже порога 0.30
